📐 How the ML Model Works
📊
Training Data

Each completed task becomes a training sample: features = difficulty + importance + planned hours, target = actual hours logged.

🧮
Linear Regression

Fits the equation: actual = w₁×difficulty + w₂×importance + w₃×planned + bias. Weights are learned from your data.

🎯
R² Score

Measures model accuracy. R² = 1.0 is perfect. R² above 0.7 means the model is a good fit. Improves as more tasks are completed.
